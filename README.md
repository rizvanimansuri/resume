# Rizvan Mansuri – Online Resume

Live: https://rizvanimansuri.github.io/resume/

Static site (plain HTML, CSS, JS) – no build step.

## Files
- `index.html` – the page
- `Rizvan_Mansuri_Resume.pdf` – ATS-friendly resume (linked from the Download/Resume buttons)
- `Rizvan_Mansuri_Resume_Designed.pdf` – designed version of the same resume
- `resume-qr.png` – QR code pointing to the live page
- `.nojekyll`, `robots.txt`, `sitemap.xml` – GitHub Pages / SEO helpers

## Deploy (GitHub Pages)
1. Create a **public** repo named `resume` under the `rizvanimansuri` account.
2. Upload everything in this folder to the repo root (including the hidden `.nojekyll`).
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
4. Wait about a minute, then open https://rizvanimansuri.github.io/resume/

To update the resume, replace `Rizvan_Mansuri_Resume.pdf` keeping the same file name.
